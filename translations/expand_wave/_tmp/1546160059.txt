TITLE: Dedicated Carrier
TAGS: Gameplay,Military,Graphics,Spaceships
DESC:
For Stellaris 4.*.* 

Adds a buildable Carrier
 NOTE: UI Overhaul Dynamic is not mandatory, this will work without it but in order to see all slots, go use it, if not, just go for the "auto-fill" or "Fill All slot" command in ship designer window. 

Current Update Features
-Rebalanced components
-Small buff to concordia
-Adjusted fleet/naval cap
-Adjusted collision (For ship behavior calculations, less chance to wander off battle on LINE config)

--------------------------------
I've always wanted a fully pledged carrier, unfortunately, only large shipmod pack got them. So here, I created my own fully pledged CV.

 Carriers 
Features:
-Somewhat Balance (I think)
-2 Types of Crew (One for Offense and One for Defense)
-Moderate Speed (Not that slow but not that fast.)
-A LOT of hangars
-Diversity (5 selectable dedicated Carrier Hull with different slots)

Technology need: Cruiser

Fleet Carrier
Features:
-Ship Color (Only for the Astro class)
-Huge
-2 Types of Crew
-Slow Speed
-A really HUGE Hanger set

Technology need: Citadel, Battleships, Extended Combat Algorithms, Self-Evolving Logic
