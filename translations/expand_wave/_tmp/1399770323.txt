EUTAB - Unique Buildings


This is a standalone module that replaces many of the reused building icons in the game, to make it achievement friendly no edits have been made to the event buildings file so a few of the icons that are in EUTAB aren't in this version.

If your game is already running EUTAB there's no need to run this as well.

No Compatibility Issues with any other mods or impact on game performance.

Image above has all the replacements included, Enjoy.
