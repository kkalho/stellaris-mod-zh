TITLE: Stellaris Performance Mod - DDS Texture Tweak
TAGS: Fixes,Graphics,Utilities,Boost,FPS,Performance
DESC:
For Stellaris 4.*.*

NOTE: THIS IS A STAND ALONE MOD. IT WILL WORK WITH OR WITHOUT THE REQUIRED ITEM.

CURRENT VERSION: 8.0
-Updated to 4.3.3
-I do not own Biogenisis, Shroud, and Infernals yet as I know, their texture files are already included ingame. (Example: Deep Space Citadel)

SETTINGS NOTE
Kindly take note that setting your graphics level to low will double the effect of this mod. (More more blurred)

Features
A mod tweaks the DDS Texture file inside GFX/MODELS folder with some exemptions:
FULLY Modified [Texture ÷2 ÷2]
[*]add_ons
[*]effects
[*]combat_items
[*]planets [Only *_normals/*_specular but ÷2 ÷2 ÷2]
[*]ships [Only *_normals/*_specular but ÷2 ÷2 ÷2]

PARTIAL Modified [Texture ÷2]
[*]galaxy_map
[*]system_map
[*]ui

Excempted 
[*]portraits
[*]planets [Only *_Diffuse]
[*]ships [Only *_Diffuse]

Example: A DDS texture size with 2048x2048 is converted into 1024x1024 then reconverted again to 512x512.
For planets/ships: They will retain their look but details will almost be flat.

Mod Load Order
Mod load order does not matter. BUT if you want to make any mods that replaces textures like this, LOAD THEM AFTER this MOD.
-Best put on the top most on any mod load order. (Then any UI mod after it so that UI's dont get blurred)
