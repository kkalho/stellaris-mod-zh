# 宣传计划（工具推广提上日程 · 2026-09-05）

> 原则：**先能接住流量，再放大流量**——工坊物品/在线版/勘误通道三条路都通了才发第一波。
> 一切宣传素材数据必须真实（与库内一致），不夸大（不写"最全""官方"）。

## 1. 宣传前置条件（缺一不发）

- [ ] 创意工坊物品上线且订阅路径验证通过（docs/WORKSHOP_PUBLISH.md DoD 全绿）
- [ ] 在线版公网可达（后续绑域名+HTTPS 后更换所有素材里的入口）
- [ ] GitHub 勘误 Issue 模板可用（详情页「报告勘误」直达）
- [ ] 素材就位：og_card.png、在线版/离线版界面截图 3-5 张、可选 15-30s GIF（搜索→筛选→详情三连）

## 2. 渠道打法（按性价比排序）

| 渠道 | 形式 | 内容要点 |
|---|---|---|
| **贴吧·群星吧** | 帖子 | 标题「整理了创意工坊 Top 1000 MOD 的中文介绍，支持拼音搜索/版本筛选（离线+在线）」；正文放截图+两个入口+一句 AI 翻译声明；回复里收集勘误 |
| **NGA·群星版** | 帖子 | 同上，语气偏硬核：强调数据字段（订阅/收藏/版本/兼容矩阵）与「查询工具书」定位 |
| **B 站专栏**（后续可配视频） | 专栏/动态 | 「群星 MOD 怎么挑」实用向，用本工具演示：新手入门场景卡→冲突检测→装机清单 |
| **知乎** | 回答现成问题 | 找「群星有哪些必装 MOD」「群星 mod 推荐」类高流量问题，答内容+顺带工具 |
| **Steam 工坊自身** | 物品 SEO | 标题含「中文/图鉴/查询」关键词；描述含玩法词（巨构/国策/舰船等高频搜索词自然出现） |
| **QQ 群/汉化组社群** | 口碑 | 先供鸽组等汉化组老师參考勘误，建立可信度后自然扩散 |

## 3. 节奏

1. **软启动**（wave6-12 精做进行中即可）：工坊物品上线 + 贴吧一个帖子试水，观察评论/勘误量，修一轮体验问题。
2. **正式宣发**（深度精做收官后）：B 站专栏 + NGA + 知乎 + QQ 群齐发，统一入口（工坊物品 + 在线版）。
3. **复播**：每完成一个重要功能（P8 分享页/CK3/HOI4 版）发一条更新动态；工坊 changenote 与页面数据日期同步。

## 4. 反馈闭环（宣传的承接面）

- 工坊评论区 = 玩家最顺手的反馈位：每天看一次，勘误类回复「已记录，下版修正」。
- GitHub Issues（预填 steam_id）：只处理数据事实类；功能建议记入 ROADMAP。
- 勘误处理流程：核实原文（details.jsonl/工坊页）→ fix 文件 → 门禁导入 → 云同步 → 在 changenote 致谢反馈者。
