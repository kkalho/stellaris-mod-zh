## 4. 节奏

1. **软启动（本周）**：贴吧 1 帖 + B 站 1 条动态，观察勘误与体验反馈，修一轮再放大。
2. **正式发（域名后）**：NGA + 知乎 + 多群同步，入口统一为域名。
3. **复播**：每完成一个重要功能（清单分享页 / CK3 界面 / HOI4）发一条更新。
